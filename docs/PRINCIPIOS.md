# Princípios

1. **Sem dono de conteúdo.** O Ágora é um cliente. Não tem API nossa, não tem banco na nuvem, não tem conta corporativa. Ninguém desliga a câmera de todo mundo com um e-mail.
2. **Identidade é chave.** `npub` / `nsec`. Sem e-mail, sem telefone, sem KYC.
3. **Interoperável.** Grupos NIP-29. Um servidor criado aqui aparece em outros clientes que falem a mesma spec.
4. **Três planos, sem atalho.** Nostr (e Tor) carregam eventos. LiveKit carrega sala. MediaMTX carrega Go Live. Tor não transporta mídia. Palco e Go Live revelam o IP ao servidor de mídia — mesmo com Tor no texto.
5. **Cifra não é Tor.** Canal público é público. DM é NIP-44. Tor esconde o caminho (IP, bloqueio de ISP), não o texto do canal.
6. **Moderação no recinto.** Cargo, kick, apagar, pin: o grupo e o relay decidem. Mute e block no cliente são só da pessoa.
7. **Código aberto de verdade.** AGPL-3.0-or-later. Quem hospeda versão modificada abre o código.
8. **Não é esconderijo.** Sem feature cujo propósito seja esconder exploração infantil. Relays e admins expulsam.
9. **PT-BR primeiro.** A interface nasce em português.
10. **Escopo em fatias.** Texto primeiro. Voz, live e Tor depois, cada um entregável sozinho.
